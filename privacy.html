Privacy Policy — Sinkron Publisher

Last updated: October 2026

1. What data we access

When the user signs in with TikTok, the tool receives only what is needed to publish videos:

  • Basic profile info (user.info.basic): display name and avatar, shown so the user knows which account is connected.
  • Permission to publish videos (video.publish) to the user's own account.
  • An access token issued by TikTok.

2. How the data is used

The data is used only to upload and publish the user's own videos to their own TikTok account and to show the publishing status. It is not used for advertising, profiling, or any other purpose.

3. Storage

Access tokens are stored only on the owner's local computer. No data is stored on external servers, and no TikTok data is sold or shared with third parties.

4. Retention and deletion

The user can disconnect the tool at any time in the TikTok app (Security > Manage app permissions), which invalidates the token. Local tokens are deleted when the user disconnects or on request.

5. Children

The tool is not intended for anyone under 18.
